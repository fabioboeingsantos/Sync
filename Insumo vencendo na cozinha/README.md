# Insumo vencendo na cozinha

Segundo simulado da UC6. Um restaurante pequeno controla o estoque em um caderno. Ingredientes vencem no fundo da geladeira, e o desperdício só aparece no fim do mês. A situação afeta o dono e o cozinheiro. Consulte as [regras do modelo](regras.md) e o [guia UC6](../GUIA-SIMULADO-UC6.md).

| Arquivo | Quando usar |
| --- | --- |
| [E1](E1.md), [CSD](Matriz-CSD.md) e [persona](persona.md) | Definir problema, público e desafio. |
| [E2](E2.md) | Entrevistar e registrar a revisão da CSD. |
| [E3](E3.md) e [MVP](htmls/E3-mvp-validade.html) | Planejar, executar e testar o MVP (abrir `htmls/E3-mvp-validade.html` direto no navegador). |
| [E4](E4.md), [roteiro](pitch/roteiro.md) e [slides](htmls/E4-pitch-slides.html) | Preparar, apresentar e exportar o pitch em PDF (`Ctrl + P`). |
| [E5](E5.md) | Organizar PDF, link e evidências. |
| [Índice de imagens](imagens/README.md) | Registrar as imagens produzidas para este tema. |
| [Agente de IA](agente_IA/agente_IA.md) | Documentar um experimento de IA, se fizer sentido para a dor. |

### Como executar os arquivos HTML (`htmls/`)
- **MVP da E3:** abra [htmls/E3-mvp-validade.html](htmls/E3-mvp-validade.html) no Chrome/Edge (botão direito → *Abrir com* → navegador).
- **Slides do Pitch (E4):** abra [htmls/E4-pitch-slides.html](htmls/E4-pitch-slides.html) no navegador (`F` para tela cheia, `T` para Claro/Escuro, botão **PDF** ou `Ctrl + P` para exportar o PDF da E5).

**Status geral:** E1 concluída, E2 concluída para treino (simulada), MVP da E3 implementado (aguardando execução do teste com outro grupo), slides e roteiro da E4 prontos (aguardando ensaio cronometrado e exportação do PDF para E5).
