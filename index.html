Da entrada ao descarte

Uma rotina para cozinhas que precisam consultar as datas antes de usar um insumo.

  1. Cadastre o lote

    Informe o nome do insumo e a validade. Acrescente quantidade e local de armazenamento quando precisar.

  2. Consulte por validade

    Confira as datas e identifique os lotes que precisam de atenção primeiro.

  3. Registre o descarte

    Ao marcar um lote vencido como descartado, ele vai para o histórico.

Preciso criar uma conta?

O estoque do piloto exige uma conta autorizada do restaurante. As demonstrações podem ser abertas sem cadastro.

As demonstrações são gratuitas?

Sim. Você pode experimentar os dois protótipos sem cobrança ou cartão.

Onde ficam os lotes cadastrados?

No piloto, os lotes ficam no banco de dados do restaurante. Cada demonstração guarda seus próprios lotes no navegador.

O que acontece se eu limpar os dados do navegador?

Os lotes das demonstrações são removidos desse navegador. Os registros do piloto continuam no banco do restaurante.

Posso usar o assistente sem microfone?

Sim. Digite os dados do lote no campo de mensagem e confira a sugestão preenchida antes de salvar.

Funciona no celular dentro da cozinha?

Sim. A interface se adapta a telas menores para consulta rápida direto no celular ou tablet.
