# Modelo reutilizável do hackathon

Copie a pasta inteira para uma pasta com o nome do novo desafio. Preencha os campos entre colchetes com as informações do novo projeto. Use [regras.md](regras.md) para conferir o padrão e o [guia UC6](../GUIA-SIMULADO-UC6.md) para consultar o processo.

| Arquivo | Quando usar |
| --- | --- |
| [E1](E1.md), [CSD](Matriz-CSD.md) e [persona](persona.md) | Entregar tema, motivo, Matriz CSD completa e desafio em uma frase na E1. O arquivo separado e a persona servem de apoio. |
| [E2](E2.md) | Entrevistar e registrar a revisão da CSD. |
| [E3](E3.md) e [htmls/](htmls/README.md) | Planejar, demonstrar e testar o MVP (arquivos HTML centralizados em `htmls/`). |
| [E4](E4.md) e [roteiro](pitch/roteiro.md) | Preparar e ensaiar o pitch (slides HTML em `htmls/`). |
| [E5](E5.md) | Organizar PDF, link e evidências. |
| [Índice de imagens](imagens/README.md) | Registrar as imagens produzidas para este tema. |
| [Agente de IA](agente_IA/agente_IA.md) e [arquitetura](agente_IA/arquitetura-passo-a-passo.md) | Documentar experimento separado de IA, se fizer sentido para a dor. |

A estrutura foi derivada do simulado [Marmita no WhatsApp](<../Marmita no WhatsApp/E1.md>). Os resultados daquele exercício pertencem ao projeto de referência. As telas, as imagens e os dados do novo projeto devem ser produzidos conforme a necessidade.
