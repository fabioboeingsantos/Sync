# Arquivos HTML do Projeto (`htmls/`)

Centralize aqui todos os arquivos HTML do desafio, nomeando cada um pela respectiva etapa:

- `E2-tela-entrevista.html` — tela exploratória da E2 (se usada na validação).
- `E3-mvp-[tema].html` — MVP manual funcional da E3 (com comentários didáticos).
- `agente-ia-[funcao].html` — experimento separado do assistente de IA para discussão em sala.
- `E4-pitch-slides.html` — slides interativos 16:9 do pitch (Arial, Claro/Escuro e exportação PDF via `Ctrl + P`).
